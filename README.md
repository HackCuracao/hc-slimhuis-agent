# HackCuraçao Slim huis: Home Assistant add-on

Statusmelding (heartbeat) naar het beheer van HackCuraçao. Zie `SECURITY.md` voor precies wat er wordt verstuurd.

## Installeren
1. Home Assistant → Instellingen → Add-ons → Add-on store → ⋮ → Opslagplaatsen → voeg deze repository toe.
2. Installeer "HackCuraçao Slim huis".
3. Vul bij Configuratie het adres en het token in dat u van ons kreeg en start de add-on.

Het token maken wij in het beheer (Slim huis → woning → Token maken) en het wordt maar één keer getoond.
